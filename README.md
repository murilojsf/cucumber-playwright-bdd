#This is a BDD Playwright automation using Cucumber as well

This project uses Playwright and Cucumber to perform automated tests for a login feature and a user update feature.
Playwright is a JavaScript-based end-to-end testing framework that allows developers to write execute tests.

## Installation

```bash
npm install

```
>**NOTE**
>
>It is necessary to have **node** installed

## Running
``` bash
# Run the automation by command line
npx playwright test

# Run the automation by command line in an UI
npx playwright test --ui

```
